# 📖 O Guia Definitivo do Software (Interativo)

Uma aplicação web estática, leve e responsiva projetada para apresentar conceitos de tecnologia e desenvolvimento de forma didática e altamente escalável. O projeto reúne **57 capítulos** estruturados de maneira interativa, permitindo que o usuário consuma o conteúdo de forma limpa e organizada através de um sistema nativo de acordeão.

---

## 🚀 Funcionalidades

*   **Exibição Sob Demanda:** Conteúdos ocultos por padrão, revelados apenas com o clique do usuário no capítulo desejado.
*   **Performance Pura (No-JS):** Toda a interatividade de abrir/fechar e animações de transição é feita utilizando **apenas HTML5 nativo e CSS3**, sem uma única linha de JavaScript.
*   **Design Fluido e Moderno:** Interface limpa, focada na legibilidade, com tipografia otimizada e paleta de cores balanceada (Estilo Clean/Modern).
*   **Totalmente Responsivo:** Adaptável para qualquer tamanho de tela, proporcionando uma excelente experiência de leitura tanto em desktops quanto em dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

Para garantir o carregamento instantâneo e a máxima eficiência energética do software, o projeto foi construído utilizando a stack web fundamental:

*   **HTML5:** Utilização de tags semânticas (`<main>`, `<header>`, `<footer>`) e elementos interativos nativos (`<details>` e `<summary>`).
*   **CSS3:** Estilização modular baseada em variáveis de sistema, Flexbox, efeitos de pseudo-classes (`:hover`, `[open]`) e animações baseadas em `@keyframes`.
